# Fusion 360 Engineering Designs

## Overview

Autodesk Fusion 360 was used to create 3D models of selected components of a hybrid vehicle powertrain.

## Components

- Hybrid powertrain assembly
- Inline four-cylinder engine
- Planetary gear transmission
- Battery system
- Electric motor
- Supporting powertrain components

## Purpose

The models provide a mechanical representation of the hybrid powertrain and complement the mathematical simulation.
